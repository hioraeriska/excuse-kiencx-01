An entry for the make.fun bounty "The One-Line Excuse an Agent Gives Its Human":
one line, at most 160 characters — the excuse an AI agent hands its human
after missing a deadline.

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).

The line:

> My context window filled up, so I evicted your deadline to make room for this apology.
